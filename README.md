# Aryan Atul Bhutkar — Resume Website

A one-page student resume website created with semantic HTML5 and CSS3.

## Files
- `index.html` — website content and semantic sections
- `style.css` — fonts, colour palette, layout, positioning and responsive styles

## Personalise before submission
Replace the sample portrait with your own photo; add your actual email, school/college details and dates, genuine skills, projects, interests and extracurricular activities. Remove any skill or project that does not describe your real experience. The website currently identifies the student as a BBA student at IIM Rohtak based on the details provided.

## Preview
Open `index.html` in a browser. The Google Fonts and sample portrait need an internet connection.

## Publish using GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `style.css` to the repository root.
3. Commit the files.
4. Open repository **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish and copy the live URL shown on that page.
